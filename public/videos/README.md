# Landing background video

Place your looped background video here:

| File | Required |
|------|----------|
| `landing-bg.mp4` | Yes (H.264, muted loop works best) |
| `landing-bg.webm` | Optional (smaller / faster load) |

**Tips**

- Use a dark, subtle abstract clip (10–30s loop, 720p–1080p).
- Keep file size under ~15 MB for faster loading.
- Replace the bundled sample `landing-bg.mp4` with your own file (same name).

The landing page overlays a soft tint so text stays readable.
